📘 How to get your own API keys (free options first)
  1. Groq (free, recommended to start): Go to console.groq.com/keys → sign up → "Create API Key" → copy the gsk_... value into the Groq API Key — Primary box above.
  2. Google Gemini (free ~1M tokens/day): aistudio.google.com/apikey → "Create API key" → paste the AIza... key into the Gemini box.
  3. Claude (paid, most capable): console.anthropic.com → add a payment method under Billing → "Create Key" → paste the sk-ant-... key.
  4. OpenAI (paid): platform.openai.com/api-keys → add billing → "Create new secret key" → paste the sk-... key.
💡 Tip: start with Groq + Gemini (both free). Add a paid key only when you need heavier reasoning. Set your Primary to the one you want used first and a Fallback for when it's busy. Keys are stored only in your own workspace.

📧 Resend Email Integration

Send branded emails to your clients (booking confirmations, portal replies, invoices). Your sender email must be verified in Resend first.

📘 How to set up Resend
  1. Sign up free at resend.com (free tier = 3,000 emails/mo).
  2. API key: resend.com/api-keys → "Create API Key" → paste the re_... value below.
  3. Verify your domain: resend.com/domains → add your domain → add the DNS records it shows you (at your domain registrar) → wait for "Verified." Your Sender Email must use that domain (e.g. hello@yourbusiness.com).
  4. No domain yet? You can still test using Resend's onboarding@resend.dev sender, but get your own domain verified before emailing real clients.

Calendar Subscription

Subscribe to your dashboard calendar from Google, Apple, or Outlook. New events you add here appear in your phone/laptop calendar within minutes — automatically. One-way (dashboard → your calendar). The URL is private to you; treat it like a password.

How to subscribe
Google Calendar: Open calendar.google.com → left sidebar → "+" next to Other calendars → From URL → paste your URL → Add calendar. Google polls every few hours.

Apple Calendar (Mac): Calendar app → File → New Calendar Subscription… → paste URL → set Auto-refresh to "Every hour".

Apple Calendar (iPhone/iPad): Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar → paste URL.

Outlook: outlook.live.com → Calendar → Add calendar → Subscribe from web → paste URL.
